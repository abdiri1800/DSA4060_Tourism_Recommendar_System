# DSA4060_Tourism_Recommendar_System
This project focuses on developing a Tourism Recommender System that helps travelers discover tourist destinations that match their interests and preferences. The system will use the Indonesia Tourism dataset, which contains information about tourist destinations and user ratings.

The recommender will analyze factors such as destination characteristics, user preferences, and previous ratings to generate personalized recommendations. For example, a user interested in cultural attractions, nature, or historical sites could receive recommendations for destinations that are similar to places they have previously rated highly.

The project will explore recommendation techniques such as content-based filtering, collaborative filtering, and potentially a hybrid approach. The performance of the recommendation models will be evaluated using appropriate metrics to determine how effectively they can recommend relevant tourist destinations.

Link to data: https://www.kaggle.com/datasets/aprabowo/indonesia-tourism-destination
